📊 Detección de Anomalías en Ventas

Proyecto de análisis de datos que detecta comportamientos anómalos en ventas usando Machine Learning.

🚀 Objetivo

Identificar:

Caídas inesperadas en ventas
Picos anormales
Patrones inusuales en el tiempo
🧠 Enfoque

Se utilizó:

Agregación temporal de ventas
Media móvil (rolling mean)
Modelo Isolation Forest
⚙️ Tecnologías
Python
Pandas
Scikit-learn
Matplotlib
📈 Resultado

El modelo detecta automáticamente días con comportamiento atípico en ventas, permitiendo:

Prevención de pérdidas
Identificación de errores o eventos especiales
📂 Dataset

Datos de ventas retail (simulados/adaptados)
